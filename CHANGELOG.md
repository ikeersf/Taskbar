### Añadido
- Estilos de barra de tareas: transparente, desenfoque, acrílico y normal.
- Opacidad ajustable y soporte para varios monitores.
- Inicio automático con Windows.
- Instalador con asistente (Inno Setup) y desinstalación limpia.
- Compilación y publicación automática de Releases con GitHub Actions.
